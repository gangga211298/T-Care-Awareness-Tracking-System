# T-Care-Awareness-Tracking-System
This project delivers a digital tool to enhance T-Care awareness and interest at Astrido Toyota Kebon Jeruk. It integrates survey results across all T-Care services, builds a centralized database, enables real-time monitoring, supports data-driven decision making, and drives preventive actions to boost T-Care service claims
